# Avatar licensing and provenance

Rowan and Mira are new characters generated with MPFB 2.0.17 using the MakeHuman system asset pack, Visemes 02, and Faceunits 01. Character meshes, skin and clothing assets, facial targets, and embedded textures derive from MakeHuman Community assets distributed under **CC0 1.0**. The clothing colors are procedural Blender materials made for these exports. No manuscript avatar files or third-party character designs were reused.

Sources: [MakeHuman system assets](https://static.makehumancommunity.org/assets/assetpacks/makehuman_system_assets.html), [Visemes 02](https://static.makehumancommunity.org/assets/assetpacks/visemes02.html), [Faceunits 01](https://static.makehumancommunity.org/assets/assetpacks/faceunits01.html), and [MPFB 2.0.17](https://github.com/makehumancommunity/mpfb2/releases/tag/v2.0.17). MPFB and Blender are generation tools; their source code is not included in the GLB files. The local reproduction script is offered under CC0 1.0.
