# Starter avatar fixtures

`avatar-motion.json` contains three seconds of authored joint positions derived
from the bundled fictional Rowan rig. `avatar-face.json` contains authored blink
and smile controller values. Neither file contains recorded performer data or
outputs from a trained model. They are distributed under this repository's MIT
license; the character assets retain their separate CC0 provenance.

The companion viewer loads these files automatically. Replace them using its
local file controls with motion/face files prepared through the documented public
data adapters. The same renderer and playback controls handle both routes.
